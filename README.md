## Getting Started
1. Download v1.95.2.
2. Drop dinput8.dll next to the game exe.
3. Launch the game.
4. Press Insert for the menu.
5. Notes in `files/notes/`.

## FAQ

**How to open reframework menu?**
Press Insert in game. If the menu does not appear, check that `dinput8.dll` sits next to the exe.

**How to uninstall reframework?**
Delete `dinput8.dll` and the `reframework` folder.

**RE4 remake?**
Separate build. This zip is Wilds + RE9.

**REFramework nightly?**
This zip tracks the Wilds + RE9 nightly line. Filename stays `REFramework-Installer.zip`.
